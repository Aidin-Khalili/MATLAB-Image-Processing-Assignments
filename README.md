# MATLAB Image Processing Assignments

![MATLAB](https://img.shields.io/badge/MATLAB-0076A8?logo=mathworks&logoColor=white) ![License: MIT](https://img.shields.io/badge/License-MIT-green.svg)

Image-processing assignments in MATLAB (B.Sc. in Computer Engineering), including point operations, morphological **erosion and dilation**, and **focus measurement** on out-of-focus images.

| Folder | Content |
|---|---|
| [Assignment4](Assignment4) – [Assignment5](Assignment5) | Basic image operations |
| [Assignment6](Assignment6) | Morphology: erosion and dilation |
| [Assignment7](Assignment7) | Out-of-focus images: inputs and results |
| [Assignment8](Assignment8) – [Assignment9](Assignment9) | Further image-processing exercises |

## Run

Open MATLAB, change the current folder to the assignment you want, and run its `.m` script.
